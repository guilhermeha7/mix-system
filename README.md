## Mix System 

### Descrição
* Mix System é um aplicativo web que possibilita unir várias músicas com extensão .wav em um único arquivo. O MixSystem sempre gera um mix de ordem aleatória.


### Como Usar
1. Insira a quantidade de músicas que você deseja unir em um mesmo arquivo
2. Informe o diretório das músicas (Todas as músicas que você deseja unir devem estar no mesmo diretório)
3. Aperte no botão "Gerar mix".


### Limitações
* No momento, o Mix System possibilita unir apenas músicas com extensão .wav.
* O MixSystem sempre vai gerar um mix de ordem aleatória.
